Pengolahan Citra Digital (22TIF0262) · Tema D: Industri dan Manufaktur

Deteksi Cacat / Kerusakan Permukaan Produk

Quality control permukaan produk berbasis pengolahan citra digital klasik: morfologi black-hat & top-hat, segmentasi ambang Otsu, deteksi tepi Canny, dan analisis kontur. Ruang lingkupnya hanya produk — buah, makanan, dan benda/produk manufaktur seperti baja pada dataset uji NEU Surface Defect Database (1.800 citra, 6 jenis cacat). Bukan untuk foto manusia: gambar yang terdeteksi berisi wajah akan ditolak otomatis dan tidak dinilai.

2. Atur Parameter

Pilih mode sesuai produknya. Mode Buah memakai analisis warna (HSV): buah disegmentasi dari latar, daun hijau dikeluarkan, lalu bercak gelap/jamur pada kulit dihitung terhadap luas kulit buah. Jeruk segar berdaun dan bertetesan air tetap dinilai dari kulitnya saja.

Geser ke 0 untuk memakai luas minimum bawaan preset. Nilai lebih besar mengabaikan bintik kecil / noise.

3. Citra Contoh Dataset

Klik salah satu contoh untuk langsung mengujinya — mode pemeriksaan menyesuaikan otomatis (contoh baja memakai Mode Baja, contoh buah memakai Mode Buah). Folder normal_sintetis adalah citra permukaan bersih hasil sintesis untuk menguji keputusan LULUS, karena dataset NEU hanya berisi citra bercacat.

Tahapan Pengolahan Citra

Setelah proses berjalan, setiap tahap pipeline akan tampil di sini: grayscale → blur → black-hat & top-hat → peta anomali → masker segmentasi → tepi Canny → hasil.

Belum ada data. Proses sebuah citra terlebih dahulu.

Dugaan jenis ditentukan dari fitur geometris kontur (rasio aspek, luas, sirkularitas) — bukan klasifikasi machine learning. Keputusan akhir: CACAT bila luas area cacat ≥ 0,8% dari luas citra, selain itu LULUS.

Dataset: NEU Surface Defect Database — Song & Yan, Northeastern University (via Kaggle). 1.800 citra grayscale 200×200 piksel: crazing, inclusion, patches, pitted surface, rolled-in scale, scratches (masing-masing 300 citra).
